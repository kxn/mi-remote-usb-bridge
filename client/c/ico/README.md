# Optional host ICO decoder

Imported wrapper, fetch hashes and pj shims from
[unicom-ble-remote-research at f293c62](https://github.com/kxn/unicom-ble-remote-research/tree/f293c62/scripts/ico_decoder).
This is compiled for the host computer, never for CH582F.

From the repository root:

```powershell
python client/c/ico/build.py
$env:RBP_ICO_LIBRARY = (Resolve-Path build/ico/ico.dll).Path
```

Build requires a native GCC/Clang compiler (`--cc` overrides discovery). The
script downloads 17 SHA-256-locked G.722.1 reference files and builds both the
shared library and offline reference demo. Downloads remain ignored by Git.
The downloaded pjproject sources contain their own Polycom/ITU and GPL notices;
those licenses apply to the resulting decoder, independently of this project's
host wrapper license. They are not relicensed by copying this wrapper.

Python finds the development build automatically; installed applications can
set `RBP_ICO_LIBRARY` or place the library beside `rbp/ico.py`. .NET accepts the
same environment variable or a library beside the application executable.
The library architecture must match the host process. Without it, clients keep
IMA support and omit ICO from their supported codec list. No import-time download
or compilation occurs. Native libraries are not included in the Python wheel.

The build also creates `build/ico/rbp_decoder.dll` (or the platform's shared
library equivalent). This ICO-enabled generic C decoder accepts both codec 1
and codec 2 through the existing `rbp_decoder_init` / `rbp_decoder_decode`
functions. The enlarged header provides caller-owned ICO state; old IMA callers
using the original structure size remain accepted and never access the extension.
Recompile with the current header to use ICO. The generic decoder allocates no
heap state. Serialize calls into the reference codec across C decoder instances. `make decoder` still builds the small IMA-only library.

`ico.h` additionally exposes the standalone ICO C ABI. Python `AudioDecoder.data()`
and .NET `AudioDecoder.Feed()` validate RBP continuity and return PCM16LE as before.
C applications keep their existing RBP/3 continuity checks. Dispose Python/.NET
decoders when aborting an unfinished stream (`close()` / `Dispose()`).

Reference output: `protocol/v3/ico-vectors.json` contains 396 captured frames and
PCM SHA-256 hashes from the research repository's pre-existing baseline WAVs.
They were not generated by this port. The research records comparison against
the vendor decoder; this port verifies those hashes again in Python and .NET.
